# Agent guidance

**Critical:** Never commit credentials or private deployment identifiers, including
cloud project IDs and account addresses. Keep them out of PR text, too. Follow
the [security guide](agents/security.md) before committing or publishing.

Read the guides relevant to your task before making changes:

- [Security](agents/security.md): private configuration, pre-push checks, and exposure response.
- [Coding style](agents/style_guide.md): JavaScript/TypeScript conventions and snake_case filenames.
- [Architecture](agents/architecture.md): library boundaries, plugins, telemetry, and resource ownership.
- [Development](agents/development.md): verification and documentation practices.

Setup, commands, and packaging are in [CONTRIBUTING.md](CONTRIBUTING.md).
Keep this file short; place detailed guidance in `agents/`.
